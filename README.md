## Согласовать со студией перед публикацией
1. **Цены «за прядь».** В DIKIDI у капсул стоят суммы 12–45 ₽ без пометки; по смыслу (и по цене «Всё включено» в Яндексе) это цена за прядь — так и подписано на сайте. Подтвердить.
2. **Фото** из 2ГИС (часть загружена гостями) и DIKIDI — нужно разрешение. Фото «до/после» — согласие клиентки.
3. **Мастера** — фото и рейтинги из DIKIDI на 10.11.2026. Ольга и Ирина (капсуляторы) без фото, поэтому на сайте не показаны.
4. **Рейтинги** — на 10.11.2026, могут измениться.
5. **Услуги «по записи»** (нанопластика, SPA, причёски, косы, детская стрижка) есть в 2ГИС, цен нет — добавить, если студия даст.
